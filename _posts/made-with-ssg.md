# Built with Static Site Generator (SSG) & Kinetic Theme

Banking On Quantum is natively compiled with [Static Site Generator (SSG)](https://github.com/sebastienrousseau/static-site-generator) using the **Kinetic** marketing theme.

## Architecture Advantages
- **Rust Native Compilation**: Sub-second full site build times.
- **Zero Third-Party CDN Dependency**: All CSS, scripts, and fonts are same-origin with strict Content Security Policy.
- **WCAG 2.2 AAA Gated**: Automated verification of color contrast and structural semantics.
- **Supply Chain Security**: Built-in CycloneDX SBOM and SRI hash verification.
