# Accessibility Statement

Banking On Quantum is built to provide universal access to all users adhering strictly to **WCAG 2.2 Level AAA** guidelines.

## Accessibility Implementation

- **High Contrast Standards**: Contrast ratios exceeding 7.0:1 for body copy and 4.5:1 for headlines across both light and dark themes.
- **Keyboard Navigation**: Full keyboard tab sequence support with prominent focus indicator rings.
- **Screen Reader Readiness**: Semantic HTML landmarks, clear hierarchical headings, and concise image descriptions.
- **Zero Motion Violations**: Respects all `prefers-reduced-motion` operating system preferences.
